수업 커리큘럼

STEP 1

Phonics

초1–초2 / 영어 첫걸음

  • 알파벳 소리와 글자 연결
  • 단모음·장모음, 이중자음 읽기
  • 사이트워드로 짧은 문장 읽기
spoken I have a red bag. 나는 빨간 가방이 하나 있어요.
STEP 2

Basic

초2–초4 / 파닉스 완료 후

  • 기초 문장 패턴 익히기
  • 짧은 이야기 듣고 읽기
  • 단어 → 구 → 문장 만들기
spoken Can I go to the bathroom? 제가 화장실에 가도 돼요?
STEP 3

Intermediate

초4–초6

  • 이유·예시를 넣어 말하기
  • 문단 단위 읽기와 요약
  • 문법을 문장 속에서 익히기
written I like summer because I can swim in the sea. 나는 바다에서 수영할 수 있기 때문에 여름을 좋아한다.
STEP 4

Advanced

초6–중3 / 중등 내신 대비

  • 중등 핵심 문법과 구문
  • 자기 생각을 담은 에세이 쓰기
  • 내신·서술형 대비
written If I had more time, I would read more books. 만약 내게 시간이 더 있다면, 나는 책을 더 많이 읽을 텐데.
