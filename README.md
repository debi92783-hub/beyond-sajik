# 비욘드잉글리쉬 사직캠퍼스 홈페이지

학원 안내 메인페이지예요.

- `index.html` — 학원 안내, 원장 소개, 커리큘럼, 소식, 상담 신청(달력·시간 선택·사전 설문)이 담긴 한 장짜리 페이지
- `admin.html` — 원장님·선생님 입장 화면(아이디 로그인), 원장님 대시보드, 선생님 수업 일지, 일정 달력, 선생님 등록 (지금은 예시 데이터, 나중에 구글 시트 연결)
  - 로그인은 시안용이에요. 계정이 그 기기 브라우저에만 저장되고 비밀번호는 해시로만 보관하지만, 정적 페이지라 실제 보안은 아니에요. 운영 전에 구글 로그인 등 서버 인증으로 바꿔야 해요.
- `apps-script.gs` — 상담 신청을 원장님 구글 시트에 저장하고 메일로 알려 주는 Apps Script
- `계획서-및-연동-설정.md` — 요구사항 정리와 구글 시트 연동 방법

`index.html` 의 `CONFIG.SHEET_URL` 이 비어 있으면 상담 신청은 메일 앱(mailto)으로 보내져요.
